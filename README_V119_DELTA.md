# SW BATTLECATS V119 DELTA

- 기준: V117 FULL + V118 DELTA
- 판본: Nintendo Switch 한국어판 `둘이서! 냥코 대전쟁`
- 모바일 데이터와 모바일 화면 동작/표시는 유지하고 Nintendo 스테이지 상세만 확장

## V119
- Nintendo 플레이 구조: **316개**
  - 화면에 이름이 확인된 목록/조건 스테이지 315개 = 스토리 144 + 레전드 112 + 스페셜 59
  - 개다래 파생 EX 1개는 존재만 검증되었고 정확한 한국어판 스테이지명은 미확인이라 이름을 임의 생성하지 않음
- 토·일 XP 3단계 중복 제거
- 레전드 완료 후 `각성의 고양이 무트` 스테이지 추가
- Nintendo 전용 스테이지 상세 데이터 추가
- 확인된 통솔력/보상/해금/보스/주요 적/공략 정보를 표시
- 확인하지 못한 통솔력·성 체력·전체 적 구성 등은 빈칸 유지
- 권장 캐릭터는 Switch 공략에서 직접 언급된 캐릭터만 연결하고, 그 외는 검증된 대응 속성만 표시

## 미완료
- 개다래 파생 EX의 정확한 한국어판 스테이지명
- 공개 Switch 자료에서 수치가 확인되지 않는 개별 스테이지 상세
- V118에서 남긴 한국판 특전 캐릭터 7종의 Nintendo 전용 원본 데이터/이미지 확보
