# SW BATTLE CATS V106 DELTA

기준: V101 FULL + V102 + V103 + V104/V105 사용자 배포 결과 확인

## 목적
V105에서 모바일 선택 상태에서 전체 데이터 로딩이 실패한 배포 회귀를 복구합니다.

## 변경
- runtime-v106을 과거 runtime 폴더에 의존하지 않는 자립형 runtime으로 구성
- manifest의 64개 데이터 파일을 runtime-v106 내부에 직접 포함
- 모바일 기본 판본을 유지
- V104의 뽑기 11개 분류/능력·대상 속성/버전 표시 변경 유지
- V103 자동 업데이트 관리 구조는 변경하지 않음
- UI/CSS/레이아웃 변경 없음

## 배포
ZIP 내부 파일/폴더를 기존 저장소 루트에 덮어씁니다.
