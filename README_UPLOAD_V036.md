# SW BATTLECATS V036 GitHub Pages 업로드본

이 폴더의 **내용 전체**를 GitHub 저장소 루트에 덮어올린다. ZIP 자체를 올리지 않는다.

- 시작: `/index.html` → `/web/`
- 상단: 검색 고정
- 하단: `특수 / 캐릭터 도감 / 적 도감 / 스테이지` 고정
- SQL 적용: 없음
- 기존 GitHub Pages: `main / (root)` 그대로 유지
- 캐릭터 이미지: 로컬 locked 이미지가 없으면 공개 저장소의 검증된 unit/form 경로를 사용한다. 네트워크/원격 파일이 없으면 `이미지 준비 중` fallback.
- 적 이미지: 검증된 explicit mapping만 사용한다.
- 추천 편성: 공식 공략 공식이 아닌 KR 15.5.0 데이터 기반 휴리스틱이며, 세계편 초반은 보수적 진행 필터를 기본 적용한다.
