# SW BATTLE CATS V100 DELTA

기준: V099

목표: 모바일 캐릭터/적 도감 전수 정리. 스테이지 성 이미지는 이번 작업에서 제외.

변경:
- 캐릭터 형태 링크와 진화 링크가 같은 대상으로 반복되는 경우, 형태 링크를 기준으로 중복 링크 버튼만 제거하고 진화 조건/설명은 유지.
- 캐릭터 획득 스테이지와 획득/해방 스테이지 보상이 겹치는 경우, 중복 대상 링크만 제거하고 별도 대상 링크는 유지.
- 적 등장 스테이지 링크가 있는 경우 `확인된 스테이지 수` 중복 카드 제거.
- KR 원본에 `仮1~仮4` 임시 문구만 들어 있는 적 설명 2건은 공식 설명으로 노출하지 않고 `공식 적 도감 설명 미수록` 처리.
- 분류 원본이 빈 속성 배열인 `항아리 성`은 기존 분류값 자체를 근거로 `속성을 가지지 않은 적`으로 표시해 속성 공백 제거.
- V098 공식 KR 속성 아이콘, V099 개발용 표시 제거, 기존 캐릭터/적/스테이지 데이터와 기능 유지.
