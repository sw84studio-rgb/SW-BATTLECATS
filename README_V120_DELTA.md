# SW BATTLECATS V120 DELTA

- 기준: V117 FULL + V118 DELTA + V119 DELTA
- 목적: 모바일/Nintendo 스테이지 상세의 출현 적 이미지 표시

## V120 변경
- 모바일 스테이지 `출현 적 > 적 구성`에 기존 enemy ID 기반 원본 적 이미지 + 한국어 이름 표시
- 기존 배율/출현 횟수/출현 타이밍 텍스트는 그대로 유지
- Nintendo 스테이지의 확인된 보스/주요 적을 기존 적 이미지 + 한국어 이름 카드로 표시
- Nintendo에서 상세 판정이 기존 scope에 포함된 적만 카드 클릭으로 적 상세 이동
- 적 도감/검색 데이터, 모바일 전투 데이터, Nintendo 스테이지 데이터는 변경하지 않음
- 기존 UI 색상/메뉴/배치 변경 없음

## 검증
- JS 문법 검사 통과
- 모바일 스테이지 출현 적 참조 고유 enemy ID: 559 / 이미지 연결 559 / 누락 0
- Nintendo 스테이지 확인 적 이름: 57 / enemy ID 매핑 57 / 이미지 연결 57 / 누락 0
- 연결된 이미지 파일 실존 검사: 누락 0
- `멍뭉이(enemy:2)` 기존 원본 이미지 연결 확인

## 미검증
- 실제 배포 환경 PC/모바일/태블릿 렌더링은 미검증
- 기존 Nintendo scope에서 적 상세 판정이 없는 일부 항목은 이미지/이름만 표시하고 상세 이동은 열지 않음
